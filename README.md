# muscle-streak

受講番号：6th-02
氏名：安 揮星

## 1. プロダクトの紹介

曜日ごとにトレーニング予定を決めて，予定どおりに続けられた回数を🔥ストリークで記録する筋トレ継続SNSです．フォローした仲間と継続状況を見せ合い，「ナイスバルク！」や応援コメントで励まし合えます．

- トレーニング記録の作成・編集・削除（日付・部位・メモ）
- 曜日ごとのトレーニング予定（部位つき）の設定
- 予定した曜日に連続でトレーニングできた回数を表示する🔥ストリーク
- 今日の予定・達成状況がわかるダッシュボード
- ユーザーページとフォロー／フォロー解除
- フォロー中の仲間の🔥ランキングと「今日まだトレーニングしていない仲間」の表示
- 記録への「ナイスバルク！」（いいね）と応援コメント

この題材を選んだ理由は，Duolingo（英語学習アプリ）のような「続けたくなる仕組み」を筋トレに取り入れたかったからです．ただし筋トレは休養日が必要なため，毎日記録する形ではなく自分で決めた曜日だけを判定するストリークにアレンジしました．また，講義のLaratterをそのまま置き換えるだけにならないようストリークをアプリの主役にし，フォローやいいねは「仲間と継続を励まし合う」ための機能として位置づけました．

## 2. こだわった点・苦労した点

こだわった点

- 予定日だけを判定するストリーク：予定のない曜日（休養日）はスキップし，予定日に記録がなかった時点で途切れるようにした．また，今日がまだ終わっていないのに 0 にならないよう，今日が予定日で未記録の場合は昨日から数えるようにした
- 講義の型の応用：記録のCRUD（1 対多），ナイスバルク！とフォロー（多対多），応援コメント（ネストしたリソース）と，講義で学んだ構成をすべて使いながら，予定とストリークという講義にない要素を組み合わせた
- 本人以外の操作をコントローラでも防止：講義ではボタンを隠すだけだった部分を，コントローラでも abort_if / abort_unless でチェックし，URL を直接開かれても他人の記録やコメントを編集・削除できないようにした（自分自身のフォロー，自分の記録へのナイスバルク！も禁止）
- N+1問題への対策：仲間のランキングでは，仲間全員の予定と記録をwith()でまとめて取得し，人数が増えてもDBへの問い合わせ回数が増えないようにした
- 入力ミスや不正な値の防止：未来の日付は記録できない，部位は選択肢以外を受け付けない，ナイスバルク！やフォローを連打しても二重登録エラーにならない（syncWithoutDetaching）ようにした
- デモ用データの作成：Seederで5人分のユーザー・予定・記録・フォロー・ナイスバルク！・コメントを自動生成し，狙ったストリーク数になるようにした

苦労した点

- 日付の判定がずれる問題：Laravel の初期設定のタイムゾーンが UTC だったため「今日」が前日扱いになることに気づき，Asia/Tokyo に変更して解決した
- 環境構築：root ユーザーで作業していたため，Sail のコンテナとファイルの持ち主が合わずパーミッションエラーが出た．.env に WWWUSER / WWWGROUP を設定し，chown で持ち主を合わせて解決した．Docker と WSL の連携が止まったときも，WSL を再起動して復旧した
- Target class [〇〇] does not exist のエラー：routes/web.php に use 文を書き忘れていたことが原因だった．エラー画面の 1 行目を読んで原因を切り分けられるようになった
- テスト環境：PHP 8.5 の非推奨警告と設定画面のレイアウトエラーでテストが通らなかったが，講義資料の手順で修正し，すべてのテストが通る状態にした

## 3. 操作方法

1. トップページから「Log in」でログインする（下記のテスト用アカウントを使用）
2. ダッシュボードで，自分の 🔥 ストリーク，今日の予定と達成状況，仲間の 🔥 ランキング，「今日まだトレーニングしていない仲間」を確認する
3. サイドバーの「予定の設定」で，トレーニングする曜日と部位を設定して保存する
4. サイドバーの「記録する」から，日付・部位・メモを入力してトレーニングを記録する（今日の予定の部位が最初から選ばれている）
5. 予定日に記録すると，ダッシュボードの 🔥 ストリークが増えることを確認する
6. 「トレーニング記録」の一覧から仲間の名前をクリックしてユーザーページを開き，「フォローする」を押す
7. 仲間の記録の「💪 ナイスバルク！」を押す（もう一度押すと取り消し）
8. 記録の詳細画面で「応援コメントする」からコメントを投稿する
